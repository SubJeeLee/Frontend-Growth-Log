# 한 번의 드래그가 픽셀이 되기까지

GDGoC KNU Frontend Study · Session 5 · Canvas API · 이준섭

[발표자료 열기](https://subjeelee.github.io/Frontend-Growth-Log/GDGoC-Canvas/) · [발표 대본](./발표대본.md)

KNUD 2026 졸업전시 사이트의 스프레이 인터랙션을 바탕으로 Canvas의 렌더링 원리, 좌표 계산, ImageBitmap과 캐시, 갱신 스케줄링을 설명하는 17장 발표자료입니다.

Space나 오른쪽 방향키로 한 단계씩 진행합니다. 왼쪽 방향키로 되돌아가며, Home은 첫 장으로 이동합니다. 구현 코드가 있는 장에서는 C로 코드를 열 수 있습니다.

폰트와 IGNITE 로고를 포함한 단일 HTML 파일이므로 내려받아 열어도 동작합니다. 2장의 실제 졸업전시 서비스는 인터넷 연결이 필요합니다. 각 장의 출처와 마지막 참고 자료에서 원본 구현과 블로그 기록을 확인할 수 있습니다.
