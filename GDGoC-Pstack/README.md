# pstack으로 살펴보는 검증 중심 개발

[발표자료 열기](https://subjeelee.github.io/Frontend-Growth-Log/GDGoC-Pstack/) · [발표 대본](./발표대본.md) · [나만의 Skill 작성 가이드](./나만의-Skill-작성-가이드.md)

GDGoC KNU 교육 세션 발표자료입니다. pstack의 작업 분류와 플레이북 구조를 소개하고, 투두 앱의 디자인·검증·기능 구현·버그 수정 사례로 검증 중심 개발 과정을 설명합니다.

18장으로 구성되어 있습니다. Space 또는 오른쪽 방향키로 진행하고, N으로 현재 대본을 열고, P로 발표자 창을 사용할 수 있습니다. 원문 이미지는 클릭해서 확대할 수 있습니다.

`index.html`은 폰트·이미지·영상이 포함된 단일 파일입니다. 내려받아 오프라인으로 열어도 동작합니다.

원본 시연은 김플립의 pstack 소개 영상과 Lauren Tan의 Grok Bot 사례에서 발췌했습니다. 각 슬라이드의 출처에서 원문과 영상 링크를 확인할 수 있습니다. 투두 앱과 상태 전환은 설명용 예시입니다.
