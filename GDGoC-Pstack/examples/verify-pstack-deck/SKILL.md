# pstack 발표자료 검증

저장소 루트에서 수정한 발표자료를 내보내고, 수강자가 사용하는 발표 조작을 확인합니다.

1. `index.html`과 `scripts/qa-flow.cjs`가 있는 프로젝트 루트인지 확인합니다. 검증 스크립트에서 요구하는 로컬 Playwright와 Chromium이 준비되어 있는지 확인합니다. 환경을 준비할 수 없으면 빠진 의존성을 보고합니다.
2. `python3 scripts/export.py`를 실행합니다. 내보내기에 실패하면 오류를 기록하고 중단합니다.
3. `node scripts/qa-flow.cjs`를 실행합니다. 이 검사는 내보낸 파일을 열고 장별 화면과 대본을 확인합니다. 이어서 키보드로 단계 이동, 대본 열기, 원본 클립 재생을 확인합니다.
4. 이번 실행의 종료 코드가 `0`이고 이번에 저장된 `reference/qa-flow.json`의 `errors`와 `overflow`가 빈 배열인지 확인합니다. 파일에 적힌 장과 단계 수를 읽고 원본 영상을 확인한 장 번호를 기록합니다.
5. 실행 명령, 실제 결과, `reference/qa-flow.json` 경로를 보고합니다. 실패한 경우 명령과 오류, 확인이 남은 항목을 보고합니다. 현재 실행의 결과가 없으면 이전 JSON을 근거로 사용하지 않습니다.

검증 과정에서 만든 화면 캡처와 결과 JSON은 다음 사람이 다시 볼 수 있도록 보관합니다.
